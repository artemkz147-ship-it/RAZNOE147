# VibeCut — Android-видеоредактор

Рабочая ветка проекта: `vibecut-video-editor`.

## Реализовано в 0.1

- импорт нескольких видео через системный выбор файлов без лишних разрешений;
- локальный предпросмотр Media3 ExoPlayer;
- таймлайн из нескольких клипов;
- разделение клипа по курсору;
- обрезка начала и конца по курсору;
- отключение звука на отдельном клипе;
- поворот по 90° с предпросмотром и экспортом;
- дублирование и удаление клипов;
- отмена последних действий;
- склейка всех клипов в один MP4;
- экспорт H.264 + AAC через Media3 Transformer;
- сохранение результата в `Movies/VibeCut`;
- интерфейс на русском языке.

## Технологии

Kotlin, Jetpack Compose, AndroidX Media3 ExoPlayer/Transformer/Effect. Целевой результат — APK для Android/RuStore.
