# Worlds

Локальная игра-угадайка по панораме: сначала выбери вселенную, затем поставь точку на карте. За совпадение мира даётся 1 000 очков, за близость к локации — до 4 000. Лучший результат хранится в браузере. Панорамы вращаются мышью или касанием; колёсико и клавиши `+` / `-` меняют масштаб.

## Запуск

```bash
npm install
npm run dev
```

## APK для Android

Проект Android находится в `android/` и создан через Capacitor. При установленном Android SDK и JDK 17+ APK можно собрать командой:

```bash
npm install
npm run android:apk
```

Готовый debug APK появится в `android/app/build/outputs/apk/debug/app-debug.apk`. Для публикации в RuStore нужен release APK с подписью своим ключом; debug APK предназначен для установки и проверки на устройстве.

## Текущий контент

Есть десять панорам и по одному раунду для каждой вселенной. Изображения — AI-сгенерированные 2:1 реконструкции узнаваемых локаций в `web-panoramas/panoramas`; они не являются фотографиями настоящих съёмочных площадок. Следующий раунд открывается после завершения предыдущего.
