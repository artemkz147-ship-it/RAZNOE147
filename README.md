# Sky Frontiers aircraft glTF2 cache

These aircraft are converted from the Flightradar24 `fr24-3d-models` repository from legacy glTF/GLB 1.0 to glTF/GLB 2.0 using Cesium `gltf-pipeline`.

The conversion changes container/version compatibility only. The aircraft meshes remain authored aircraft meshes; no procedural aircraft geometry is generated.

Source: https://github.com/Flightradar24/fr24-3d-models
