# Форма 365

Офлайн Android-приложение под годовой план снижения веса с сохранением мышц.

## Что внутри
- 52 недели с четырьмя этапами и разгрузочными неделями.
- 3 безопасные тренировки A/B/C без упражнений, требующих страховки.
- Учёт рабочих весов и рекомендация повышения нагрузки.
- Прогрессия к первому подтягиванию.
- Простое бюджетное питание без рыбы и овсянки.
- Воскресенье: один читмил, не чит-день.
- Учёт веса, шагов, белка, сна, замеров и тренировок.
- Локальное хранение данных на устройстве.

## Сборка
Gradle 8.11.1, Android Gradle Plugin 8.10.1, JDK 17, compileSdk 35.
