Без рыбы и овсянки. Максимально простая и бюджетная база.

Один читмил, не чит-день. Обычный белковый завтрак → один вкусный приём пищи → обычный лёгкий ужин.

Покупки на неделю

3. Овощи — заморозка, капуста, морковь, огурцы/помидоры по бюджету.
4. Соусы и специи можно: следи только за маслом и сладкими соусами.
