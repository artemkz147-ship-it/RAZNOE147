# НейроФото — офлайн AI-фоторедактор для Android

Ветка: `neuro-photo-editor`

## Цель

Собрать Android APK, который редактирует фотографии нейросетью локально на телефоне, без обязательного API и без собственного сервера.

## База

- UI/мобильная интеграция: `rmatif/Local-Diffusion` (Apache-2.0), зафиксированный upstream commit `184b7f92cf2f810e7d5eb4b04b190a5da829005f`.
- Inference: `leejet/stable-diffusion.cpp` (MIT).
- Базовая модель для Full-сборки: Stable Diffusion 1.5 GGUF Q4_0 (CreativeML OpenRAIL-M).
- Android: arm64-v8a, полностью локальный inference.

## Возможности приложения

1. **Стилизация фото (img2img)** — превратить фото в кино, аниме, иллюстрацию, киберпанк, фэнтези, пластилин, комикс и другие стили.
2. **Текстовое изменение деталей** — описать, что нужно изменить, и задать силу преобразования.
3. **Локальное редактирование по маске (inpainting)** — стереть/заменить предмет, одежду, фон, волосы и т. п.
4. **Расширение кадра (outpainting)**.
5. **ControlNet / Scribble-to-Image** — набросок или контур как жёсткая структура результата.
6. **PhotoMaker** — работа с референсным портретом.
7. **LoRA** — подключение дополнительных бесплатных стилей/персонажей.
8. **Upscale** — увеличение разрешения результата.
9. **До/после**, сохранение результата и история параметров.
10. **CPU / Vulkan / OpenCL** — выбор ускорения в зависимости от телефона.
11. **Flash Attention / TAESD / VAE tiling** — режимы экономии RAM и ускорения.

## Сборки

- `NeuroPhoto-lite.apk` — движок и интерфейс без встроенного тяжёлого чекпоинта; позволяет выбрать локальную модель.
- `NeuroPhoto-full.apk` — плановая автономная сборка с встроенной SD1.5 Q4 моделью. Нужна отдельная проверка лимитов размера APK/артефакта и установки на реальные устройства.

## Принцип

Никаких платных AI API и обязательных облачных серверов. Вся обработка изображения выполняется на устройстве. Сеть может использоваться только для необязательной загрузки дополнительных моделей/LoRA, если пользователь сам этого захочет.
