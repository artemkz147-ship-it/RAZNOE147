# Shadow Ronin — Путь Тени

Большой мобильный 2D action-platformer с оригинальным силуэтным визуальным стилем, вдохновлённый атмосферой кинематографичных ninja-платформеров, но не копирующий чужие персонажи, уровни или графику.

## Масштаб
- 5 миров, 30 уровней (6 в каждом мире)
- 5 уникальных боссов
- 5 архетипов врагов + вариации поведения
- платформинг: double jump, wall slide, wall jump, dash
- бой: 3-ударное комбо мечом + сюрикены
- ловушки: шипы, пилы, пропасти, движущиеся платформы
- секретный свиток на каждом уровне
- чекпоинты и автоматическое сохранение
- 3 звезды за уровень
- карта мира, прокачка, настройки и статистика

## Миры
1. Лес Безмолвия
2. Горы Ворона
3. Пылающий Монастырь
4. Топи Духов
5. Цитадель Тени

## Прокачка
- Стойкость — здоровье
- Клинок — урон мечом
- Шаг тени — рывок
- Фокус — энергия и сюрикены

## Технологии
- Phaser 3
- Vite
- Capacitor Android
- GitHub Actions для воспроизводимой сборки APK

Все игровые изображения первой версии генерируются самим проектом в runtime из векторных примитивов Phaser. Игра не требует внешнего CDN, сервера или AI API после установки APK.

## Сборка
```bash
npm install
npm run build
npx cap add android
node scripts/patch-android.mjs
npx cap sync android
cd android && ./gradlew assembleDebug
```

GitHub Actions делает эти шаги автоматически и сохраняет `app-debug.apk` как artifact `Shadow-Ronin-debug-apk`.
