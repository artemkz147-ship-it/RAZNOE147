# Hell Creek — требования к среде T. rex

Финальный `environment.glb` должен изображать тёплую позднемеловую пойменную среду, а не современный тропический лес.

- Слоистая растительность и вариативный грунт/влажные участки.
- Ветер через шейдер или анимацию без дорогой физики каждой ветки.
- LOD/visibility ranges для растительности.
- Экономный свет и тени для мобильного GPU.
- Профили плотности растительности для Performance / High / Cinema.
- Фоновая аудиосцена поставляется локально в OGG.
