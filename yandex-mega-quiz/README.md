# Умниверсум — Большая викторина для Яндекс Игр

Готовый HTML5-проект викторины с адаптивным интерфейсом, ежедневными заданиями, прогрессией, облачными сохранениями, рекламными наградами и глобальным лидербордом.

## Что уже есть

- 1226 вопросов/вариантов в 19 темах без 18+ контента.
- Режимы: Классика, Блиц, Выживание, Лестница знаний, Верю/не верю, Эксперт, Марафон, Испытание дня.
- Тематические раунды по каждой категории.
- Серии правильных ответов, очки за скорость и сложность.
- XP, уровни, монеты, лиги и достижения.
- 3 ежедневных задания, ежедневный сундук и испытание дня.
- Ежедневки используют `ysdk.serverTime()` при наличии SDK.
- Облачные сохранения через `player.getData()` / `player.setData()` плюс локальный fallback.
- Глобальный рейтинг через актуальный `ysdk.leaderboards` API.
- Fullscreen-реклама после каждого третьего завершённого раунда.
- Rewarded video: удвоение монет после раунда и возврат жизни в «Выживании».
- `LoadingAPI.ready()`, `GameplayAPI.start()/stop()`, обработка `game_api_pause/game_api_resume`.
- Safe-area для мобильных устройств с вырезами.
- Клавиши 1–4 / A–D на десктопе.

## Настройка Яндекс Игр

1. В Консоли Яндекс Игр создайте лидерборд с техническим именем `global_score`.
2. Тип результата: numeric. Сортировка: по убыванию.
3. Загрузите содержимое папки проекта ZIP-архивом так, чтобы `index.html` лежал в корне архива.
4. Для локального запуска SDK недоступен — игра автоматически включает локальный fallback. На платформе используется `/sdk.js`.
5. Перед публикацией прогоните игру через debug-панель Яндекс Игр и проверьте Game Ready, рекламу, паузу/возобновление и лидерборд.

## Структура

- `index.html` — оболочка приложения и подключение `/sdk.js`.
- `styles.css` — адаптивный интерфейс и safe-area.
- `questions.js` — банк вопросов и генераторы учебных вариантов.
- `yandex.js` — изолированный мост к SDK Яндекс Игр.
- `game.js` — состояние, режимы, ежедневки, прогресс, UI и игровой цикл.
- `assets/favicon.svg` — иконка вкладки/локального теста.

## Важно перед релизом

Лидерборд должен быть создан в Консоли с тем же техническим именем, иначе SDK вернёт 404. Для рекламных блоков игра останавливает gameplay-разметку на время показа; собственных сторонних рекламных блоков проект не использует.
