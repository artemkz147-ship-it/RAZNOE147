# Умниверсум — Большая викторина для Яндекс Игр

HTML5-викторина для Яндекс Игр с адаптивным интерфейсом, большим банком вопросов, ежедневными и недельными активностями, прогрессией, облачными сохранениями, рекламными наградами и лидербордами.

## Что есть в версии 2.0

- 1226 вопросов/вариантов в 19 темах без 18+ контента.
- 8 режимов: Классика, Блиц, Выживание, Лестница знаний, Верю/не верю, Эксперт, Марафон, Испытание дня.
- Тематические раунды по каждой категории.
- Серии правильных ответов, очки за скорость и сложность.
- XP, уровни, монеты, лиги и достижения.
- Автоматические ежедневные задания: по умолчанию 6 штук — 3 обычных, 2 сложных и главное «Задание дня».
- Ежедневный набор строится из серверной даты и меняется сам без обновления игры.
- Ежедневный сундук за закрытие всего набора.
- Событие дня с меняющимися бонусами: наука, Блиц, категории, экспертные вопросы, серии, Марафон, воскресный кубок.
- 5 недельных заданий и большой недельный сундук. Набор меняется по понедельникам.
- 28-дневный календарь входа. Пропуск дня не обнуляет прогресс календаря.
- Отдельное «Испытание дня» — одинаковые 12 вопросов для всех игроков на текущую дату.
- Отдельный дневной лидерборд по лучшему результату Испытания дня.
- Глобальный рейтинг через актуальный `ysdk.leaderboards` API.
- Ежедневки и недельные активности используют `ysdk.serverTime()` при наличии SDK.
- Remote Config через `ysdk.getFlags()` с локальными значениями по умолчанию.
- Облачные сохранения через `player.getData()` / `player.setData()` плюс локальный fallback.
- Миграция старого сохранения v1 → v2 без сброса XP, монет, статистики и достижений.
- Fullscreen-реклама после каждого третьего завершённого раунда.
- Rewarded video: удвоение монет после раунда и возврат жизни в «Выживании».
- `LoadingAPI.ready()`, `GameplayAPI.start()/stop()`, обработка `game_api_pause/game_api_resume`.
- Safe-area для мобильных устройств с вырезами.
- Клавиши 1–4 / A–D на десктопе.

## Лидерборды в Консоли Яндекс Игр

Создайте два лидерборда:

1. `global_score` — глобальный рейтинг игры.
2. `daily_score` — рейтинг Испытания дня.

Для обоих используйте числовой результат и сортировку по убыванию. `daily_score` хранит дату внутри числового результата: новый календарный день автоматически становится выше предыдущих, а интерфейс показывает только записи текущего дня. Таким способом один постоянный лидерборд работает как ежедневный без создания нового leaderboard каждый день.

Если лидерборд с нужным техническим именем не создан в Консоли, SDK вернёт 404.

## Remote Config

Игра запрашивает флаги один раз при старте. Если серверная конфигурация недоступна, применяются значения, зашитые в билд.

Поддерживаются флаги:

- `daily_quest_count` — число ежедневных заданий, от 3 до 6. По умолчанию `6`.
- `daily_chest_coins` — монеты из сундука дня. По умолчанию `500`.
- `daily_chest_xp` — XP из сундука дня. По умолчанию `750`.
- `weekly_enabled` — `true` / `false`.
- `weekly_chest_coins` — монеты из сундука недели. По умолчанию `1200`.
- `weekly_chest_xp` — XP из сундука недели. По умолчанию `1800`.
- `calendar_enabled` — `true` / `false`.
- `daily_lb_enabled` — `true` / `false`.
- `special_event_enabled` — включает специальное событие вместо обычного события дня.
- `special_event_title` — название спецсобытия.
- `special_event_category` — технический ID категории. Пустое значение означает бонус ко всем наградам за раунды.
- `special_event_multiplier` — множитель спецсобытия, например `1.5` или `2`.

ID категорий для `special_event_category`:
`geography`, `history`, `science`, `space`, `nature`, `human`, `literature`, `art`, `music`, `cinema`, `technology`, `sports`, `language`, `math`, `logic`, `culture`, `food`, `transport`, `games`.

Пример: включить «Неделю космоса» без загрузки нового архива:

- `special_event_enabled = true`
- `special_event_title = Неделя космоса`
- `special_event_category = space`
- `special_event_multiplier = 2`

После завершения события верните `special_event_enabled = false`.

## Как считаются активности

Ежедневные задания отслеживают ответы, правильные ответы, раунды, разные категории, разные режимы, серии, очки, сложные вопросы, быстрые ответы до 5 секунд, раунды без 50/50 и пропусков, отдельные категории и режимы. Поэтому новый набор отличается не только числами, но и типами цели.

Недельные задания отслеживают ответы, точность, раунды, очки, категории, режимы, прохождение Испытания дня в разные даты, идеальные раунды и количество полностью закрытых ежедневных наборов.

## Структура

- `index.html` — оболочка приложения и подключение `/sdk.js`.
- `styles.css` — адаптивный интерфейс, safe-area, календарь и интерфейс активностей.
- `questions.js` — банк вопросов и генераторы вариантов.
- `yandex.js` — мост к SDK, облаку, рекламе, Remote Config и двум лидербордам.
- `game.js` — состояние, режимы, ежедневки, события, недели, календарь, прогресс и UI.
- `assets/favicon.svg` — иконка вкладки/локального теста.

## Перед публикацией

1. Создайте `global_score` и `daily_score` в Консоли Яндекс Игр.
2. При желании создайте перечисленные флаги Remote Config. Это необязательно: локальные defaults уже есть.
3. Упакуйте содержимое папки так, чтобы `index.html` лежал в корне ZIP.
4. Проверьте Game Ready, рекламу, паузу/возобновление, облачное сохранение и оба лидерборда через инструменты Яндекс Игр.
5. Проверьте мобильные и десктопные размеры окна, включая устройства с safe-area/вырезом.
