# ФайлМастер — офлайн-комбайн файлов для Android / RuStore

Ветки: `filemaster-offline` (рабочая) и `filemaster-full-1.0` (синхронизированная 1.0-линия).

## Состояние

Текущая проверенная сборка: **1.0.0-rc2**, `versionCode 11`, minSdk 29, targetSdk 36.

RC2 проходит обязательный CI-контур: JUnit → Android Lint → assembleDebug → проверка целостности APK → проверка RU/EN OCR и DEX → загрузка installable APK.

## Принципы

- без сервера, регистрации и API-ключей;
- после установки ничего не докачивается;
- OCR русского и английского встроен в APK;
- документы пользователя не отправляются в сеть;
- результаты сохраняются через MediaStore в `Загрузки/ФайлМастер`;
- входные временные файлы проверяются по свободному месту, подозрительные расширения нормализуются;
- незавершённые MediaStore-файлы удаляются при ошибке записи.

## Реализовано

### PDF
- объединение, разделение, извлечение/удаление страниц, поворот, обратный порядок, нумерация и crop;
- фото → PDF, PDF → JPG/TXT, извлечение встроенных изображений;
- PDF → редактируемый DOCX, эвристический XLSX, визуальный PPTX;
- многостраничный визуальный редактор: ручка, маркер, текст, линии, прямоугольники, штампы;
- destructive redaction выбранных областей;
- заполнение AcroForm text/checkbox/radio/choice и конструктор новых text/checkbox полей;
- сжатие, пересборка, водяной знак, очистка метаданных, сравнение;
- пароль/снятие известного пароля;
- пакетные PDF-операции;
- рукописная подпись;
- PKCS#12 `.p12/.pfx` CMS/PKCS#7 подпись и локальная проверка.

### Сканер / OCR
- single-page и многостраничный скан;
- ручные четыре угла и перспективное преобразование;
- автоулучшение документа;
- OCR изображений и PDF RU+EN полностью офлайн.

### Документы / таблицы / презентации
- DOCX/ODT/TXT-подобный текстовый редактор с сохранением в DOCX/ODT/TXT/PDF;
- DOCX/ODT → TXT/PDF;
- TXT/HTML/Markdown/RTF → TXT/PDF/DOCX/ODT;
- XLSX/CSV/TSV редактор;
- XLSX → CSV/PDF, все листы → CSV/PDF, отчёт по формулам;
- CSV/TSV → XLSX;
- PPTX → TXT/PDF.

### Изображения
- compress/resize/crop/rotate/flip/grayscale;
- JPG/PNG/WebP convert и batch;
- водяные знаки и очистка метаданных;
- SVG → PNG/JPG;
- TIFF → PNG и multi-page TIFF для поддерживаемых baseline/PackBits/Deflate вариантов;
- HEIC/GIF/AVIF/другие форматы через системный Android ImageDecoder, когда кодек доступен на устройстве.

### Архивы
- создать ZIP, AES-256 ZIP, 7Z, TAR.GZ;
- просмотреть ZIP/7Z/RAR без распаковки;
- распаковать ZIP/7Z/RAR/TAR/GZ/BZ2/XZ;
- ZIP-редактор: добавить/удалить/переименовать и сохранить новой копией;
- многотомный split ZIP и сборка частей;
- защита от path traversal при собственной распаковке.

### Файлы
- история результатов;
- встроенный файловый менеджер: поиск, фильтрация, сортировка, open/share/delete/rename.

## Ограничения, которые не маскируются

- сложная Word/Excel/PowerPoint-вёрстка не гарантируется 1:1: локальные Office-конвертеры ориентированы на текст/табличные данные, PDF→PPTX сохраняет визуальные страницы;
- RAR создаётся не может — только просмотр/распаковка;
- лёгкий TIFF-декодер не покрывает все экзотические TIFF-кодеки;
- ГОСТ/квалифицированная российская КЭП не объявляется проверенной без теста на реальном сертификате/устройстве;
- debug APK предназначен для тестирования; production RuStore требует постоянного release-keystore пользователя.

## Основные компоненты

- PdfBox-Android — Apache-2.0;
- Tesseract4Android — Apache-2.0;
- Apache Commons Compress — Apache-2.0;
- Zip4j — Apache-2.0;
- Junrar — распаковка RAR;
- Bouncy Castle jdk18on — криптография;
- AndroidSVG — SVG rasterization;
- fileloom-tiff-bitmap-factory — pure Kotlin TIFF decoder, Apache-2.0.
