# ФайлМастер — офлайн-комбайн файлов для Android / RuStore

Ветка: `filemaster-offline`

## Жёсткие требования проекта

- без сервера;
- без API-ключей;
- без регистрации;
- после установки ничего не докачивается;
- OCR-модели русского и английского языка встраиваются в APK на этапе сборки;
- пользовательские документы не покидают устройство;
- результаты сохраняются в `Загрузки/ФайлМастер` через Android MediaStore;
- целевой Android API 36, минимальный Android 10 (API 29);
- сборка APK воспроизводится GitHub Actions.

## Реально реализовано в alpha 0.1

### PDF
- объединение нескольких PDF;
- разделение PDF на отдельные страницы;
- несколько изображений JPG/PNG → один PDF;
- PDF → JPG для всех страниц;
- видимая рукописная подпись пальцем на последней странице PDF;
- открытие PDF через системное «Открыть с помощью» и быстрые действия.

### OCR
- офлайн OCR изображений;
- русский + английский;
- `rus.traineddata` и `eng.traineddata` входят в APK;
- результат показывается на экране и сохраняется TXT-файлом.

### Архиватор
- создание ZIP;
- создание 7Z;
- распаковка ZIP;
- распаковка 7Z;
- распаковка RAR;
- защита от path traversal при собственной распаковке ZIP/7Z;
- результаты распаковки сохраняются в отдельную папку в `Загрузки/ФайлМастер`.

## Следующие модули

1. PDF: поворот/удаление/перестановка страниц, водяные знаки, номера страниц, пароль, шифрование, формы, аннотации, извлечение изображений.
2. Подпись: выбор страницы и позиции; сохранённые подписи; криптографическая подпись сертификатом и проверка подписи.
3. Сканер: камера, автообрезка, коррекция перспективы, фильтр документа, OCR после сканирования.
4. Изображения: resize/crop/compress/WEBP/HEIC/TIFF/метаданные/пакетная обработка.
5. Текст: TXT/Markdown/HTML/RTF просмотр и редактирование.
6. Таблицы: CSV/TSV просмотр и редактирование; затем XLS/XLSX/ODS через Android-совместимый Office-движок после отдельной проверки runtime-совместимости.
7. Документы: DOC/DOCX/ODT чтение/экспорт после проверки Android-совместимого движка.

## Использованные компоненты

- `PdfBox-Android` — Apache-2.0.
- `Tesseract4Android` — Apache-2.0; Tesseract работает локально.
- `Apache Commons Compress` — Apache-2.0.
- `Junrar` — распаковка RAR; UnRAR license разрешает распространение для распаковки, но не реализацию RAR-сжатия.

## Почему Word/Excel пока не включены в alpha

Обычный `poi-ooxml` нельзя без проверки считать полноценным Android-движком: часть Apache POI зависит от отсутствующих на Android `java.awt` классов и XML/STAX-особенностей. Поэтому Office-функции не замаскированы заглушками и не объявлены готовыми до реального теста сборки/runtime.

## Сборка

GitHub Actions workflow `.github/workflows/filemaster-android.yml` на каждом push в ветку `filemaster-offline`:

1. устанавливает JDK/Gradle/Android SDK;
2. скачивает официальные `rus`/`eng` Tesseract traineddata **только на этапе сборки**;
3. упаковывает их в APK;
4. собирает debug APK;
5. публикует APK как Actions artifact `FileMaster-offline-debug-apk`.

Debug APK предназначен для тестирования. Для RuStore production APK/AAB нужен постоянный release-keystore; приватный ключ не должен храниться в репозитории.
