# ФайлМастер — офлайн-комбайн файлов для Android / RuStore

Рабочая ветка: `filemaster-offline`
Версия: `1.0.0-rc1` (`versionCode 10`)

## Принципы проекта

- без сервера и API-ключей;
- без регистрации;
- после установки ничего не докачивается;
- OCR русского и английского языка входит в APK;
- пользовательские документы не отправляются в интернет;
- результаты сохраняются через Android MediaStore в `Загрузки/ФайлМастер`;
- минимальный Android 10 (API 29), target/compile SDK 36;
- сборка APK воспроизводится GitHub Actions;
- production-ключ подписи не хранится в репозитории.

## Реализовано в 1.0 RC1

### PDF

- объединение нескольких PDF;
- разделение на отдельные страницы;
- извлечение, удаление, поворот и обратный порядок страниц;
- нумерация страниц;
- crop одинаковых полей;
- изображения → PDF;
- PDF → JPG и TXT;
- PDF → DOCX: редактируемый текст с разрывами страниц;
- PDF → XLSX: эвристическое распознавание строк/колонок;
- PDF → PPTX: каждая страница сохраняется как визуальный слайд;
- извлечение встроенных изображений;
- три уровня растрового сжатия;
- пересборка/repair;
- водяной знак;
- удаление метаданных/XMP;
- сравнение двух PDF по тексту;
- пароль и снятие известного пароля;
- пакетное сжатие, поворот, очистка метаданных и другие batch-операции;
- многостраничный визуальный редактор: ручка, маркер, текст, линии, прямоугольники и штампы;
- destructive redaction: выбранная область уничтожается при пересборке страницы, а не закрывается поверх исходного слоя;
- AcroForm: заполнение текстовых полей, checkbox, radio и choice/list;
- конструктор новых текстовых полей и checkbox с выбором области на странице;
- видимая рукописная подпись;
- криптографическая подпись PDF сертификатом PKCS#12 `.p12/.pfx` через CMS/PKCS#7;
- локальная проверка встроенных CMS-подписей.

### Сканер и OCR

- быстрый скан одной страницы;
- многостраничная скан-сессия → один PDF;
- автообрезка и контраст документа;
- ручная коррекция четырёх углов с перспективным преобразованием;
- OCR изображений RU + EN;
- OCR всех страниц PDF RU + EN;
- `rus.traineddata` и `eng.traineddata` упаковываются внутрь APK.

### Документы

- DOCX → TXT/PDF;
- ODT → TXT/PDF;
- TXT/HTML/Markdown/RTF → PDF;
- HTML/Markdown/RTF → TXT;
- текстовые форматы → DOCX/ODT;
- встроенный редактор DOCX/ODT/TXT-подобных документов с сохранением новой копии в DOCX/ODT/TXT/PDF.

### Таблицы

- XLSX → CSV;
- экспорт всех листов XLSX в отдельные CSV;
- XLSX → PDF;
- все листы XLSX → один PDF;
- CSV/TSV → XLSX;
- формулы, начинающиеся с `=`, сохраняются как формулы при создании XLSX;
- отчёт по книге: листы, строки, ячейки и формулы;
- встроенный табличный редактор XLSX/CSV/TSV для простых данных.

### Презентации

- PPTX → TXT;
- PPTX → текстовый PDF;
- PDF → визуальный PPTX со страницами как слайдами.

### Изображения

- JPEG-сжатие;
- resize;
- crop;
- поворот;
- горизонтальное отражение;
- grayscale;
- улучшение фотографии документа;

### Архивы

- создание ZIP, AES-256 ZIP, 7Z и TAR.GZ;

## Использованные компоненты

- `PdfBox-Android` — Apache-2.0;
- `Tesseract4Android` — Apache-2.0;
- Tesseract `tessdata_fast` RU/EN — модели встраиваются на этапе CI;
- `Apache Commons Compress` — Apache-2.0;
- `Zip4j` — Apache-2.0;
- `Junrar` — распаковка RAR;
- `AndroidSVG` — SVG-рендеринг;

- Bouncy Castle — криптография/CMS.

## Честные ограничения

- DOCX/ODT/PPTX/XLSX не используют встроенный LibreOffice/MS Office. Сложная вёрстка, плавающие изображения, SmartArt, макросы, диаграммы и часть стилей при редактировании/конвертации могут упрощаться.
- PDF → XLSX использует эвристическое разбиение текста и не гарантирует восстановление сложной табличной структуры.
- PDF → PPTX сохраняет внешний вид страниц как изображения, а не реконструирует исходные редактируемые объекты.
- TIFF-декодер поддерживает baseline/uncompressed, PackBits и Deflate/Adobe Deflate; LZW, JPEG-in-TIFF, CCITT, tiled и другие редкие варианты могут не открыться.
- RAR создаётся только сторонними RAR-совместимыми продуктами: приложение умеет распаковывать RAR, но не создавать его.
- PKCS#12/CMS-подпись компилируется и упаковывается; российская квалифицированная КЭП/полная ГОСТ-цепочка доверия не заявляется как сертифицированная без проверки на реальном сертификате и инфраструктуре доверия.
- Debug APK предназначен для тестирования. Для RuStore production APK/AAB нужен постоянный release-keystore через безопасное хранилище/CI secrets.

## Сборка

`.github/workflows/filemaster-android.yml`:

1. ставит JDK 17, Gradle и Android SDK 36;
2. скачивает официальные `rus`/`eng` Tesseract traineddata только во время сборки;
3. помещает OCR-модели в assets APK;
4. выполняет `:app:assembleDebug`;
5. публикует installable artifact `FileMaster-offline-debug-apk`.
